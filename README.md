# Zenvy

## Description

Zenvy est une application web e-commerce développée en PHP et MySQL.

Le projet permet :

- L'inscription des utilisateurs
- La connexion sécurisée
- La gestion des sessions
- L'affichage d'un catalogue de produits
- La gestion d'un panier d'achat
- L'intégration de pratiques DevOps

## Technologies utilisées

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitLab
- Docker
- Docker Compose
